# NCRRS test website

Test website for the proposed North Carolina Radio Resource Society. For review only; this is not an operational mentoring or request intake service.

Published with GitHub Pages from the main branch, repository root. The files in this repository are the public site only. Asset files are at the root to support browser upload. The maintained local source is the docs folder in NCRRS Website; prepare_github_test.py produces this upload copy.

The site has 140 research club entries, not confirmed participants. ARRL affiliation is either listed in the researched ARRL directory or unconfirmed. The research date is November 19, 2026. Listings do not establish current activity.

The public contact email is intentionally blank. Message preparation happens locally and does not send or store a request online. Public directory data excludes personal phone numbers, personal emails and registered office addresses. The proposed society has no governing authority over clubs.
